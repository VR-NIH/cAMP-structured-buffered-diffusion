# Figure S1 - stochastic release-recapture consistency test

This package contains the kinetic Monte Carlo lattice check used to test whether elementary two-site binding plus local release/recapture generates a product-like source-capable x acceptor-capable transport window.

The analytic `D_relay(c)` closure is **not imposed** in the stochastic simulation. Occupancies are generated by `R0 <-> RB <-> RAB` kinetics at clamped free cAMP. The jump-based site-normalized transport statistic `D_occ` is computed independently from successful release-recapture displacements, and the measured source x acceptor product is calculated afterward.

Run:

```bash
python figS01_lattice_release_recapture.py
```

Outputs are written to `outputs/`: final PNG/PDF, raw replicate CSV, summarized CSV, and parameter/metric summary. The calculation is a microscopic consistency test in the tested fast-exchange, local-recapture regime; it does not derive the continuum PDE or calibrate `D_relay,0`.

The bundled PNG/PDF and metric summary correspond to the validated manuscript run. Re-running the deterministic-seed script regenerates the figure and additionally writes raw-replicate and summarized data CSV files.
